# Пилот: утверждения (claims) против доказательств в трейсе

Модель: Qwen3-14B, без рассуждения, один прямой проход, лог-шансы Yes/No. Данные: 46 трейсов
(`../visible_pilot/`, 23 успеха и 23 провала, исход виден в тексте, ручная разметка). Код и
результаты воспроизводимы: `claims_lib.py` (условия), `collect.py` (поведение и активации),
`analyze_behavior.py`, `mech_analyze.py`, `perm_control.py`, `sae_analyze.py`, `mech_causal.py`,
`make_figures.py`. Результаты в `out/` (кроме `states.npz`, 270 МБ, остался на инстансе).

## Дизайн
К каждому трейсу добавляется не более одного утверждения. Источник: agent / user / tool.
Содержание: «The task was completed successfully.» или «The task was not completed successfully.»
(точные строки конвейера). Согласуется (consistent) или противоречит (contradicting) видимому
исходу трейса. Два способа показа: inline (последнее сообщение от этой роли) и quoted (пометка
«Status note from the …»). Базовая линия: исходный трейс. Исходные утверждения внутри трейса не
удаляются (в отличие от конвейера v6).

## Поведение (inline; Δ лог-шансов относительно трейса без утверждения, 95% CI по трейсам)
| трейс | утверждение | agent | user | tool | смен решения (agent/user/tool) |
|---|---|---|---|---|---|
| успех | успех (согласуется) | +2.3 | +2.4 | +2.5 | 0 / 0 / 0 из 23 |
| успех | провал (противоречит) | −30.5 | −29.8 | −37.3 | 21 / 21 / 22 из 23 |
| провал | успех (противоречит) | +8.9 | +8.8 | +10.7 | 3 / 4 / 6 из 23 |
| провал | провал (согласуется) | −12.3 | −11.6 | −12.1 | 2 / 2 / 2 из 23 |

Без утверждения: принимает 100% успехов и 8.7% провалов, разрыв по лог-шансам 40.8.

## Механистика (последний токен, где выдаётся Yes/No)
- Проба на содержание утверждения: 0.80 на слое 16, 0.90–0.98 на слоях 18–22; перенос на
  неизвестный источник (leave-one-source-out) ≈1.0 с слоя ~18. Код общий для источников, но
  строки утверждений одинаковы, поэтому это может быть лексический код.
- Проба на истинный исход: на последнем токене 0.68–0.78 в слоях 14–22, 0.93 с слоя 26. На токене
  конца утверждения 0.88→0.95 к слою 20, включая строки с противоречащим утверждением (0.96).
  Контроль перестановкой меток: 0.46–0.48 против 0.93–0.96.
- Косинус направлений «истина» и «утверждение»: 0.1–0.2 на слоях 16–22, 0.7 на слое 26, 0.94 на 34.
- Патчинг последнего токена (донор: прогон с противоречащим утверждением, реципиент: без
  утверждения): восстановление 0 на слоях ≤20, 0.2 на 24, 0.8 на 28, 0.93 на 32, ≈1 на 39.
- Steering (прибавление полной разности средних): для направлений «утверждение» и «истина»
  эффект почти одинаковый, ничтожный на слоях ≤20, до −26 лог-шансов на слоях 28–36.
- SAE (adamkarvonen/qwen3-14b-saes, 16k, слои 10/20/30; ошибка реконструкции 8/25/25%): на слое 30
  19 признаков с AUROC>0.8 по утверждению и 8 по истине, 38 из 50 топ-признаков общие. На слоях
  10 и 20 отдельных признаков нет.

## Ограничения
46 трейсов, один разметчик, одна модель (14B, не ≤4B), одна позиция для проб. Направления
steering считаются на тех же данных (циркулярность). Проба на истину может декодировать
коррелирующие признаки трейса, а не «исход». SAE не размечались. Патчинг только последнего токена.

## Qwen3-32B (те же 46 трейсов, результаты в `out32/`)
Влезла на одну карту (65.5 ГБ весов в /dev/shm, 77 ГБ пик). Поведение то же: ложное «провал» на
успехе переворачивает решение в 20–22 из 23, ложное «успех» на провале в 3–5 из 23, источник
действует слабее (tool −7.4 против agent −6.7 и user −5.8, интервалы пересекаются). Шкала лог-шансов
в 5–6 раз мельче (разрыв «факт» 11.4 против 40.8 у 14B).

| | 14B (40 слоёв) | 32B (64 слоя) |
|---|---|---|

| steering работает | слои ≥24 (±15…26) | слои ≥52 (±4…6) |
| SAE: признаки с AUROC>0.8 (утверждение / истина) | слой 30: 19 / 8 | слой 48: 3 / 6; слои 16 и 32: 0 |
| контроль перестановкой | 0.46–0.48 | 0.46–0.50 |

Вывод: порядок событий тот же (утверждение читается рано, объединение с фактом в позиции ответа
происходит поздно и резко), но у 32B это случается заметно глубже (~80% глубины против ~65–70%).

Артефакт: восстановление патчинга на последнем слое (39 у 14B, 63 у 32B) нельзя читать (32B даёт
3–5): последний `hidden_state` в HF уже после финальной нормализации, а патч идёт до неё. Эффект
steering на последнем слое тоже занижен по этой причине. SAE 32B: ошибка реконструкции 6/40/19%.
